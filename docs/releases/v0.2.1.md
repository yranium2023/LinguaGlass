# LinguaGlass v0.2.1 — macOS 26 原生测试版

这是 LinguaGlass 首个可分发的原生 macOS 测试版本，面向 Apple Silicon 与 macOS 26。

## 主要功能

- 使用原生 SwiftUI 重构主界面、设置页和双语悬浮字幕。
- 使用 Apple Speech 在本机生成英文临时字幕与最终字幕。
- 使用 Core Audio Process Tap 捕获系统音频，不捕获屏幕画面。
- 支持系统输出设备、麦克风设备、输入增益和实时音量反馈。
- 接入 DeepSeek 流式增量翻译，支持领域、上下文与课程术语表。
- DeepSeek API Key 保存在 macOS 钥匙串；启动时读取一次，翻译期间不重复访问。
- 支持浅色/深色模式、八种强调色、界面字号和黑白应用图标。
- 支持可拖动、缩放、收起和鼠标穿透的悬浮字幕。
- 支持会话记录自动跟随最新以及 Markdown、TXT、JSON 导出。

## 下载

下载 `LinguaGlass-0.2.1-macOS-arm64-Test.zip`，解压后将 `LinguaGlass.app` 拖入
“应用程序”文件夹。

本测试包未使用 Apple Developer ID 签名与 Apple 公证。第一次启动请右键应用选择
“打开”；如果仍被阻止，请在“系统设置 → 隐私与安全性”中点击“仍要打开”。

## 系统要求

- Apple Silicon Mac；
- macOS 26 或更高版本；
- 系统音频模式需要“系统音频录制”权限；
- 麦克风模式需要麦克风权限；
- 中文翻译需要测试者自己的 DeepSeek API Key。

## 已知限制

- 当前不包含 Intel `x86_64` 构建。
- 当前测试包没有 Developer ID 和公证票据，因此首次启动需要手动确认。
- DeepSeek 翻译需要网络连接，并会产生 API 使用费用。
- Apple Speech 的语言模型、断句和最终定稿行为由系统框架管理。
